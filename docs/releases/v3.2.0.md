# UGreen Control v3.2.0

- iDX6012 增加电源、网络和六个盘位的灯光控制、跑马灯接管，以及双风扇同步调速、设备智能模式、自定义温控、兼容温控预设、来电开关和 WOL。已有指定主板的灯光、调速和设置回读实测。实际断电恢复与关机唤醒待验证。
- DXP4800 GT 支持 CPU 和系统风扇独立调速、八点自动温控及实验性来电开关。改进 LED 多总线识别、U.2／M.2 物理盘位映射和 EC 占用诊断。风扇、灯光和断电恢复仍需在目标 fnOS NAS 上复测。
- 固定 PWM 和 WOL 设置按机型保存，应用启动时恢复。WOL 和 RTC 的可用机型取自上游目录，设置结果以设备回读为准。
- BIOS 和风扇使用 UGREEN-NAS-Hardware 0.4.0 的 x86_64 构建。灯控继续使用应用附带的 ugreen_leds_cli。

适用平台为 x86 飞牛 fnOS 0.9.27 及以上，应用标识为 App.Native.UGreenLED。可用同名 SHA-256 文件校验版本化 FPK。
